# FlowConvert 文件存储设计

## FileStore

基于磁盘的文件管理系统，用于存储生成的文件和下载的临时文件。

### 结构

```rust
pub struct FileStore {
    base_dir: PathBuf,      // 根目录
    ttl_hours: u64,         // 文件 TTL
}

pub struct FileEntry {
    name: String,           // 唯一标识
    original_name: String,  // 原始文件名
    path: PathBuf,          // 磁盘路径
    created_at: Instant,    // 创建时间
}
```

### 核心方法

#### register(src_path, base_name)

将文件注册到存储并返回下载路径名：

```rust
pub fn register(&self, src_path: &str, base_name: &str) -> Result<String, String> {
    let name = new_id(4);  // 8位随机 hex
    let ext = Path::new(base_name).extension()...;
    let dest = self.base_dir.join(format!("{}_{}", name, ext));
    copy_file(src_path, &dest)?;
    Ok(name)
}
```

返回的 `name` 用于 URL：`/api/download/{name}`

#### download(name)

根据 name 查找并返回文件：


### 自动清理

后台线程定期清理过期文件：

```rust
pub fn spawn_cleanup(&self) {
    tokio::spawn(async move {
        loop {
            tokio::time::sleep(Duration::from_secs(3600)).await;
            self.cleanup();
        }
    });
}

fn cleanup(&self) {
    let mut entries = self.entries.lock();
    entries.retain(|_, entry| entry.created_at.elapsed() < Duration::from_secs(3600 * self.ttl_hours));
}
```

## VideoJobStore

内存中的视频任务状态存储。

### 结构

```rust
pub struct VideoJobStore {
    jobs: Mutex<HashMap<String, VideoJob>>,
    ttl_minutes: u64,
}

pub struct VideoJob {
    task_id: String,
    status: JobStatus,     // Pending/Processing/Completed/Failed
    download_url: Option<String>,
    error: Option<String>,
    created_at: Instant,
    acquired_by: Option<String>,  // 客户端 IP
}
```

### 核心方法

| 方法 | 说明 |
|------|------|
| `create(task_id)` | 创建新任务 |
| `get(task_id)` | 查询任务状态 |
| `set_status(task_id, status)` | 更新状态 |
| `set_error(task_id, error)` | 设置错误信息 |
| `acquire(task_id, client_ip)` | 标记为处理中 |
| `release(task_id)` | 完成处理 |
| `gc()` | 清理过期任务 |

### 状态转换

```
Pending → Processing → Completed
                ↓
              Failed
```

### TTL 清理

```rust
fn gc(&self) {
    let mut jobs = self.jobs.lock();
    jobs.retain(|_, job| {
        job.created_at.elapsed() < Duration::from_secs(60 * self.ttl_minutes)
    });
}
```

## 持久化策略

| 数据 | 存储方式 | 持久化 |
|------|---------|--------|
| 生成文件 | 磁盘 (output/) | 是，TTL 清理 |
| 临时文件 | 磁盘 (tmp/) | 否，即时清理 |
| 视频任务 | 内存 (HashMap) | 否，重启丢失 |
| 配置 | 环境变量 | - |

## 安全特性

1. **路径隔离**: 所有文件存储在 base_dir 子目录下
2. **命名规范**: 仅使用 8 位随机 hex 作为文件名
3. **TTL 限制**: 自动清理过期文件释放磁盘空间
4. **权限限制**: 文件权限由文件系统控制，建议 644
