# FlowConvert 配置管理

## 配置结构

```rust
pub struct Config {
    pub port: String,           // 监听端口
    pub base_url: String,       // 公开访问的基础 URL
    pub data_dir: String,       // 数据存储根目录
    pub tmp_dir: PathBuf,       // 临时文件目录
    pub out_dir: PathBuf,       // 输出文件目录
    pub max_size: usize,        // 最大上传大小 (字节)
    pub max_url: usize,         // 最大 URL 下载大小 (字节)
    pub ttl_hours: u64,         // 文件 TTL (小时)
    pub agnes_api_key: String,  // Agnes API 密钥
    pub agnes_base_url: String, // Agnes API 端点
    pub sensenova_key: String,  // SenseNova API 密钥
    pub sensenova_base: String, // SenseNova API 端点
}
```

## 配置加载顺序

1. **环境变量** (优先级最高)
2. **配置文件** (`config.toml` 或 `.env`)
3. **默认值**

### 环境变量列表

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `FLOWCONVERT_PORT` | `8080` | HTTP 监听端口 |
| `FLOWCONVERT_DATA_DIR` | `./data` | 数据根目录 |
| `FLOWCONVERT_BASE_URL` | `http://localhost:8080` | 公开访问 URL |
| `FLOWCONVERT_MAX_SIZE` | `52428800` | 最大上传大小 (50MB) |
| `FLOWCONVERT_MAX_URL` | `20971520` | 最大 URL 下载 (20MB) |
| `FLOWCONVERT_TTL_HOURS` | `24` | 文件保留时间 (小时) |
| `FLOWCONVERT_AGNES_API_KEY` | `""` | Agnes API 密钥 |
| `FLOWCONVERT_AGNES_BASE_URL` | `""` | Agnes API 端点 |
| `FLOWCONVERT_SENSENOVA_KEY` | `""` | SenseNova API 密钥 |
| `FLOWCONVERT_SENSENOVA_BASE` | `""` | SenseNova API 端点 |
| `FLOWCONVERT_PYTHON` | `python3` | Python 解释器路径 |
| `RUST_LOG` | `info` | 日志级别 |

## 目录结构

```
data/
├── output/    # 生成的文件 (带 TTL 清理)
├── tmp/       # 临时文件
└── jobs/      # 视频任务状态 (内存，重启丢失)
```

## 配置示例

### 基本配置

```bash
export FLOWCONVERT_DATA_DIR=/var/lib/flowconvert
export FLOWCONVERT_PORT=8080
./target/release/flowconvert
```

### AI 服务配置

```bash
export FLOWCONVERT_AGNES_API_KEY=your-agnes-key
export FLOWCONVERT_AGNES_BASE_URL=https://agnes.example.com/v1
export FLOWCONVERT_SENSENOVA_KEY=your-sensenova-key
export FLOWCONVERT_SENSENOVA_BASE=https://sensenova.example.com/v1
./target/release/flowconvert
```

### 完整配置

```bash
export FLOWCONVERT_DATA_DIR=/data
export FLOWCONVERT_BASE_URL=https://flowconvert.example.com
export FLOWCONVERT_PORT=8080
export FLOWCONVERT_MAX_SIZE=104857600  # 100MB
export FLOWCONVERT_TTL_HOURS=48
export FLOWCONVERT_AGNES_API_KEY=xxx
export FLOWCONVERT_AGNES_BASE_URL=https://api.agnes.example.com
export FLOWCONVERT_PYTHON=/usr/bin/python3
./target/release/flowconvert
```

## 配置验证

启动时检查必要目录：

```rust
pub fn ensure_dirs(&self) -> Result<(), String> {
    for dir in [&self.tmp_dir, &self.out_dir] {
        std::fs::create_dir_all(dir)
            .map_err(|e| format!("创建目录失败 {}: {}", dir.display(), e))?;
    }
    Ok(())
}
```

如果目录创建失败，进程会退出并打印错误信息。
